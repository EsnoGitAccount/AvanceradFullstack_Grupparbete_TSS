# AvanceradFullstack_Grupparbete_TSS

Naming Conventions:
PascalCase for React components
camelCase for typescript-files
kebab-case for folders
kebab-case for css-classes

PascalCase for classes, enums, methods and files
camelCase for variables
_camelCase with underscore for PRIVATE variables

Branch naming:
prefix/descriptivebranchname
  Prefixes:
  feature/ - Adds new functionality or features
  bugfix/ - Bugfix
  hotfix/ - Fixing critical errors
  chore/ - Maintenance work or refactoring
  docs/ - Documentation
